# AGENTS.md

## Repository Structure

- `src/` contains the React and TypeScript frontend.
- `src/App.tsx` contains application state, BLE discovery, Tauri events,
  preference persistence, and the current screens.
- `src/components/ui/` contains local shadcn/Radix UI source components.
- `src/index.css` contains Tailwind setup and the dark Sage Green theme.
- `src-tauri/src/lib.rs` contains the BLE transport, `tenover` protocol session,
  Tauri commands and events, and live TTS output.
- `src-tauri/capabilities/default.json` defines permissions for the main window.
- `src-tauri/gen/apple/` is generated by Tauri but contains required iOS
  customizations and is partly version-controlled.

## Architecture Constraints

- BLE scanning and device selection begin in the frontend.
- Garmin protocol processing belongs in Rust through `tenover`.
- Keep frontend `R10Shot` fields synchronized with Rust event serialization.
- Keep Tauri command names and `r10://*` event names synchronized across layers.
- Live shot speech is generated in Rust. Frontend TTS is only for the settings
  preview.
- Shot speeds enter frontend state as mph and are converted only for display.
- Preferences use Tauri Store file `settings.json` and key `preferences`.
- Browser mode must guard all native Tauri API calls.
- Production assets and fonts must continue to work offline.

## User Interface

- Preserve the bottom navigation order: Stats, Log, View, Settings.
- Stats, View, and Settings should fit the iOS viewport without page scrolling.
- Log may scroll within its content panel.
- Do not introduce fake shots into Stats or Log. Empty sessions use empty states.
- The settings voice preview uses a hardcoded realistic reference shot and must
  never read from the live shot or session log.
- Use existing shadcn source components and Sage Green theme tokens rather than
  adding an unrelated visual system.

## Native and Signing Safety

- Do not broaden Tauri capabilities without documenting the requirement.
- Do not commit Apple Team IDs, certificates, provisioning profiles, API keys,
  device identifiers, archives, IPAs, or signing exports.
- Local signing belongs in ignored `src-tauri/tauri.ios.conf.json` or the
  `APPLE_DEVELOPMENT_TEAM` environment variable.
- Treat iOS project regeneration as destructive. Preserve Bluetooth usage text,
  CoreBluetooth, background modes, entitlements, and project build scripts.
- Do not add `dist`, `node_modules`, `src-tauri/target`, Apple `build`, Apple
  `Externals`, or generated Tauri schemas to version control.

## Validation

Run before completing code changes:

```sh
make check
make test
```

`make check` runs frontend lint/build and Rust format/check. `make test` runs
the frontend unit tests (vitest) and Rust unit tests (`cargo test --lib`). CI
runs both. Tests cover pure logic in `src/lib/format.ts` and
`src-tauri/src/voice.rs`; the App render test runs in browser mode so all
native Tauri calls are guarded out.

Targeted commands:

```sh
npm run lint
npm run build
npm run test
cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Use `make run` for the incremental desktop development loop. Real BLE and R10
behavior must be verified in Tauri with hardware; browser mode is insufficient.
